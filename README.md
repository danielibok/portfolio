## About

A responsive personal portfolio built from scratch with HTML, CSS and vanilla JavaScript. The design takes its cue from streaming apps: a dark theme, a banner hero, projects shown as numbered "titles", and a project page laid out like a show page.

## Pages

- `index.html`: hero, About Me, projects, and contact (email and WhatsApp)
- `project.html`: full write-up of the USB Security Rollout project
- `scam-checker/`: Naija Scam Message Checker, a working tool that flags red flags in suspicious SMS/WhatsApp messages (live project)

## Structure

```
index.html
project.html
css/style.css   shared styles, CSS variables, flexbox and grid
js/main.js      mobile menu, header on scroll, screenshot lightbox
images/         project screenshots (sensitive details blurred)
```

## Run locally

Open `index.html` in a browser. No build step needed.
