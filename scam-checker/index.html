    How it works

    The checker looks for patterns that show up again and again in Nigerian scam messages. Each pattern carries a weight, and the weights add up to a score. A message asking for your BVN plus a link to a fake bank site scores far higher than one that just says "urgent".

    Links get extra attention. The checker flags shortened links, links to raw IP addresses, cheap domain endings like .xyz, and any link that uses a bank's name but isn't the bank's real website.

    This is a rule-based first version. For my final year project I'm training machine learning models to do the same job, including on scams that have been reworded by AI to slip past rules like these.
