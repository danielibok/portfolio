Password Strength Checker

Type a password to see how strong it is and why. Everything runs in your browser. Nothing you type is sent anywhere.

Start typing to check a password.

Checklist

  • At least 12 characters
  • A lowercase letter
  • An uppercase letter
  • A number
  • A symbol (like ! @ # ?)
  • Not a commonly used password
  • No obvious patterns (aaa, 123, qwerty, or a word plus a year)

How it works

The score comes from two things. First, how many possible passwords an attacker would have to guess, based on the length and the kinds of characters used. Second, penalties for the shortcuts attackers try first: common passwords, keyboard runs and repeated characters.

The crack time assumes an offline attack at ten billion guesses per second, which is realistic for a modern graphics card against a weakly hashed password.
